# 💰 FinSight AI
### Your Personal Financial Intelligence Platform

FinSight AI is an AI-powered personal finance management platform designed to help users manage expenses, track savings, plan budgets, monitor financial goals, and receive intelligent financial insights.

---

## 🚀 Overview

Managing personal finances can be difficult without proper planning and analysis. FinSight AI helps users understand their financial habits and make smarter decisions through budgeting tools, goal tracking, expense management, and AI-powered recommendations.

---

## ✨ Features

### 👤 Financial Profile
- Create a personalized financial profile
- Store salary, income sources, expenses, and savings information
- Update profile anytime

### 💳 Expense Management
- Add expenses quickly
- Categorize transactions
- View expense history
- Monitor spending habits

### 📊 Smart Analytics
- Analyze monthly expenses
- Track income vs expenses
- Monitor financial health

### 🎯 Goal Tracking
- Multiple Short-Term Goals
- Multiple Long-Term Goals
- Goal progress monitoring
- Savings planning

### 🤖 AI Financial Advisor
- Personalized recommendations
- Spending analysis
- Saving suggestions
- Budget improvement advice
- Goal planning guidance

### 💬 AI Chat Assistant
- Interactive financial assistant
- Budget-related questions
- Savings guidance
- Expense management support
